# Тренажёр «Словарь безопасности»

Мобильное веб-приложение (PWA) для изучения 118 терминов информационной безопасности:
изучение с иллюстрациями, тесты по разделам, интервальное повторение, итоговый экзамен.
Работает без интернета после первого открытия, прогресс хранится только на устройстве.

Без внешних сервисов, трекеров и аналитики.
